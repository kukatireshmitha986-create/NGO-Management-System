# NGO Management System

A Full Stack NGO Management System developed using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

## 📌 Project Overview

This project is designed to help NGOs manage their daily operations digitally. It provides a user-friendly interface for users and administrators to access information, register, and manage donations efficiently.

---

## ✨ Features

- Home Page
- About Us
- User Registration
- User Login
- Dashboard
- Donation Management
- Contact Page
- MongoDB Database Integration
- REST API using Express.js

---

## 🛠 Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas

## 🚀 Installation

1. Clone the repository

```
git clone https://github.com/kukatireshmitha986-create/NGO-Management-System.git
```

2. Install dependencies

```
npm install
```

3. Start the backend server

```
node server.js
```
